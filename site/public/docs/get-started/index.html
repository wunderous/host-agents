Tutorial

Get started

Outcome. In about ten minutes you will have a Host Agent listening on your machine and an authenticated tools/list from Cursor, Claude Desktop, or another MCP client. No mutations yet — discovery only.

What you will need

  • Linux or WSL2 (host execution is Linux-only)
  • Network access for npx @opute/host-agent or a Go toolchain to build from source
  • An MCP client that speaks Streamable HTTP

Fastest path (npm launcher)

  1. Start the agent 
    export MCP_AUTH_TOKEN=dev-token
npx -y @opute/host-agent start --background
npx -y @opute/host-agent url
# → http://127.0.0.1:3014/mcp

    The launcher defaults OPUTE_REMOTE_AGENT_ID to local-host-agent. Confirm health:

    curl -sS http://127.0.0.1:3014/health
  2. Connect your MCP client

    Paste the JSON from Connect an MCP client. The Bearer token must match MCP_AUTH_TOKEN.

  3. List tools, then read the host

    Run tools/list (or your client’s catalog view). Then call get_host_info. You should get structured JSON — not a shell transcript.

From-source path

  1. Build 
    git clone https://github.com/wunderous/host-agents.git
cd host-agents
make build   # → dist/opute-host-agent
  2. Set identity and auth 
    export OPUTE_REMOTE_AGENT_ID=local-host-agent
export OPUTE_INFRA_PROVIDER_ID=incus
export OPUTE_STANDALONE_STATE_DIR="$HOME/.opute/standalone"
export MCP_AUTH_TOKEN=dev-token
  3. Check, then serve 
    ./dist/opute-host-agent --check
./dist/opute-host-agent
# http://127.0.0.1:3014/mcp

    Then connect a client and list tools as in the fastest path above.

Do not enable mutations yet. Standalone mutating tools stay denied until OPUTE_STANDALONE_ALLOW_MUTATIONS=true. Finish discovery first.

You succeeded when

  • GET /health returns JSON including your agent id
  • tools/list (or get_capability_catalog) completes without 401
  • get_host_info returns structured host facts
Trust boundary. Bearer auth gates /mcp. Write-only fields come back as [redacted]. This process is not Platform — do not reuse platform.opute.io credentials here.
