Diátaxis

Documentation

Opute Host Agent is a Streamable HTTP MCP server that executes typed infrastructure assignments on a Linux host — guests, Kubernetes, registries, tunnels — with fail-closed identity and redacted observations.

It meets the need to drive real hosts from an IDE or Platform without shell folklore. Useful if you run Incus guests, K3s, or public exposure and want a revisioned tool catalog instead of ad-hoc scripts.

Organized by what you need to do, following Diátaxis. Public origins opute.io / www.opute.io are Host Agent dogfood — not Platform (platform.opute.io / mcp.opute.io).
