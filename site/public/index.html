For infrastructure operators and agent authors

Inspect your Linux hosts through an authenticated AI client.

Opute Host Agent gives operators and agent authors a typed MCP connection to host facts and the capabilities this host offers. Start with a read-only check. Opute Platform coordinates authorized work across hosts.

Run a read-only host check How Host Agent and Platform fit

How it works

  1. Run the agent beside the Linux host you want to inspect. Incus and Kubernetes are optional for host facts.
  2. Connect an MCP client to its loopback HTTP endpoint with a Bearer token.
  3. Read before acting with the live typed catalog and read-only host tools.

Built for operators and agent authors who already run real infrastructure. For Opute Platform, visit platform.opute.io.

What you can inspect

Host factsRead host identity and the tools supported by the connected agent. VM inventory, when Incus is configuredDiscover existing guests before selecting any separate mutating action. Kubernetes inventory, when configuredDiscover cluster state through the available Kubernetes provider.
