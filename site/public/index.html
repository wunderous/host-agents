The operating loop

A tool call can become checked, recoverable work.

Host-local recipes package versioned inputs and a plan. The Host Agent runs that plan against this host, checks observed readiness when the plan declares it, and retains the run for inspection.

  1. DiscoverRead the live, revisioned MCP catalog and its schemas.
  2. AdmitAuthenticate, resolve the target, and check whether a write is allowed.
  3. Execute & verifyRun typed actions with readiness checks, retry, and compensation where the plan declares them.
  4. InspectRead the durable plan result and the observed resource state.

A host-local recipe runs declared steps on one host. For work across hosts, Platform coordinates the plan and Host Agent executes each host-scoped action. The local K3s test covers one guest failure, not failure of the physical host or a user-facing serving path; see the availability guide.
